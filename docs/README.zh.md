# AI Translate for Telegram

一个 Telegram 用户脚本，用你选择的 AI 模型翻译你的消息，并且不会把你说话的方式抹平。

你发出的消息在发送前被翻译，只在你开启的聊天里。你收到的消息则在你需要时翻译，从这条消息的菜单里调用。它用的是 [Discord 版 AI Translate 插件](https://github.com/mozumidesu/ai-translate)的翻译核心，提供商也一样。

## 为什么还要再做一个翻译

机器翻译是为文章做的。聊天不是文章。它用小写字母，话说一半，靠颜文字撑着，少一个句号本身就在表达什么。大多数翻译都会悄悄把这些收拾干净，于是对面收到的像是别人写的公文。

这个脚本就是为了不去动它而做的。你没写的标点它不会补上，你留作小写的字母它不会改成大写，你换行的位置它照旧保留，而且它知道颜文字是一张脸，不是要翻译的词。

## 它能做什么

自动翻译按聊天单独开启，所以只在你真正需要的对话里起作用。左键点击输入栏的翻译按钮会打开面板；右键点击，或者按住 Shift 点击，则开关当前聊天。聊天开启期间，按钮会显示为强调色。

你输入的内容会等到译文出来再发，所以对方只会看到译文。编辑过的消息按你输入的原样发出，这样你可以亲手修正一段译文。粗体、斜体、删除线、剧透、链接、提及、自定义表情、引用、代码和代码块，在译文里都留在原来的位置。唯一会丢掉的是下划线。如果翻译失败，消息会被扣下，显示原因，你的文字回到输入框；你也可以在设置里改成直接发送未翻译的原文。

收到的任何内容都可以从消息的右键菜单翻译，答案出现在旁边的卡片里。当翻译本身也帮不上忙时，因为缩写、只在某个国家用的词，或者两个人之间的玩笑，同一菜单里的 **解释** 会说出是哪种语言，把缩写展开，并讲清楚对方想说什么。这一项要你在设置里自己打开。

打开 **把最近的消息作为上下文**，对话最近的几条消息就会随每次请求一起发出，所以一句干巴巴的「嗯」或者「粘贴不上」也能按原意传达。这一项要你自己打开，因为它会把别人的消息发给你的提供商。你也可以固定自己的词汇：永远不翻译的词、固定一种译法的术语、用于你自己的语法性别，以及对对方是否使用敬语。

单条消息也能保留自己的一部分。把一个词或一句话放在两个反斜杠之间，`\carpe diem\`，它就会原样发出，只去掉反斜杠；行首的反斜杠则保留整行。代码永远不会被翻译，不管是写在反引号里，还是设成了代码格式。

**AI Learn** 是为你正在学的语言准备的。在设置里打开它，在你开启的聊天里，用目标语言的文字写的内容会按你输入的原样发出，下面附上母语者会写出的版本，改过的词会标出来。这一行只有你看得到。设置里的 **改过的地方** 保留最近五十条，在你自己消息的菜单里点 **纠正** 会再问一次。

你发出的消息下面可以留下原文，只有你自己看得到，便于确认你实际输入的内容；这一项要你自己打开。像 `/start` 这样的机器人命令，以及机器人按钮发出的内容，都按原样发出。界面支持 16 种语言，除非你另行指定，否则跟随 Telegram 的语言。

## 提供商

API 密钥由你自己提供，并且一直是你的。脚本没有自己的翻译服务器，也从不会看到别人的密钥。

| 提供商 | 免费额度 |
|---|---|
| Groq | 有 |
| Google Gemini | 有 |
| Z.ai GLM | 有，而且在前两家被挡住的地方也能用 |
| Anthropic Claude | 没有 |
| 其他（任何兼容 OpenAI 的 API） | 取决于提供商 |

第一家后面最多可以再放四家备用。当第一家繁忙、额度用尽或拒绝请求时，翻译会自动走下一家，并弹出一条简短的通知，说明为什么跳过了第一家，只弹一次，不会每条消息都弹。

你的密钥留在用户脚本管理器的存储里，请求经由管理器发出，而不是从页面发出。别人的消息只有在你要求翻译或解释其中一条时，或者 **把最近的消息作为上下文** 开着的时候，才会到达你的提供商。

## 安装

AI Translate for Telegram 只在浏览器里的 Telegram Web 中运行，别处都不行：Telegram 的应用无法扩展。Telegram Web 的两个客户端都能用，Web A 和 Web K。

装上 [Tampermonkey](https://www.tampermonkey.net/) 或者别的用户脚本管理器，然后打开 [ai-translate.user.js](https://github.com/mozumidesu/ai-translate-telegram/raw/main/dist/ai-translate.user.js)。管理器会询问是否安装，之后便从那里自动保持更新。打开 [web.telegram.org](https://web.telegram.org/) 并刷新页面。

然后点击输入栏的翻译按钮，按 **插件全部设置**，或者在用户脚本管理器的菜单里找到同一项，选择一个提供商并粘贴你的密钥。脚本第一次连到你的提供商时，管理器可能会问是否允许：请允许这个地址，在 Tampermonkey 里点 **Always allow domain**。然后开启一个聊天，就完成了。

## 更新

用户脚本管理器会按它自己的时间表，从这个仓库的 `main` 分支查找新版本。设置最下面的 **检查更新** 会立刻去问，如果有新版本，就在管理器里打开新的脚本：在那里确认，然后刷新页面。

## 卸载

在用户脚本管理器里删掉这个脚本。没有装别的东西，所以也没有别的要删。

## 反馈

设置页面顶部的信封会打开一个窗口，用来提交错误报告和需求，也可以附上截图。支持服务器的链接也在同一个窗口里。一份报告包含你写的内容、你附上的截图、你的 Telegram 名字和 id（好让回复能找到你），以及你在用的构建版本。它从不包含任何密钥或设置。你也可以在 GitHub 上[提交 issue](https://github.com/mozumidesu/ai-translate-telegram/issues)。
