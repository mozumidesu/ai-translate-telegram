# AI Translate for Telegram

userscript สำหรับ Telegram ที่แปลข้อความของคุณด้วยโมเดล AI ที่คุณเลือก และแปลโดยไม่ทำให้วิธีเขียนของคุณเรียบไปหมด

ข้อความที่คุณส่งจะถูกแปลก่อนส่งออก ในแชทที่คุณเปิดไว้ ส่วนข้อความที่คุณได้รับจะแปลเมื่อคุณสั่ง จากเมนูของข้อความนั้น มันใช้แกนการแปลของ[ปลั๊กอิน AI Translate สำหรับ Discord](https://github.com/mozumidesu/ai-translate) พร้อมผู้ให้บริการชุดเดียวกัน

## ทำไมต้องมีตัวแปลอีกตัว

การแปลด้วยเครื่องถูกสร้างมาเพื่องานเขียนเป็นเรื่องเป็นราว แต่การแชทไม่ใช่แบบนั้น มันเป็นตัวพิมพ์เล็ก พูดค้างไว้ครึ่งทาง อยู่ได้ด้วยคาโอโมจิ และการไม่ใส่จุดก็กำลังสื่อบางอย่าง ตัวแปลส่วนใหญ่เก็บกวาดสิ่งเหล่านี้ไปอย่างเงียบ ๆ และสิ่งที่ไปถึงอีกฝั่งก็อ่านเหมือนจดหมายแบบฟอร์มที่คนอื่นเขียน

ตัวนี้สร้างขึ้นเพื่อไม่ไปยุ่งกับมัน มันจะไม่เติมเครื่องหมายวรรคตอนที่คุณไม่ได้เขียน ไม่เปลี่ยนตัวพิมพ์เล็กที่คุณตั้งใจทิ้งไว้ให้เป็นตัวใหญ่ เก็บการขึ้นบรรทัดใหม่ไว้ตรงที่คุณวางไว้ และรู้ว่าอิโมติคอนคือหน้าคน ไม่ใช่คำที่ต้องแปล

## มันทำอะไรได้บ้าง

การแปลอัตโนมัติตั้งแยกตามแชท ดังนั้นมันจะทำงานเฉพาะในบทสนทนาที่คุณต้องการจริง ๆ คลิกซ้ายที่ปุ่มแปลในแถบพิมพ์เพื่อเปิดแผงควบคุม คลิกขวาหรือกด Shift ค้างแล้วคลิกเพื่อเปิดหรือปิดแชทปัจจุบัน ระหว่างที่แชทเปิดอยู่ ปุ่มจะเป็นสีเน้น

สิ่งที่คุณพิมพ์จะรอจนคำแปลเสร็จ อีกฝ่ายจึงเห็นแต่คำแปลเท่านั้น การแก้ไขข้อความจะออกไปตรงตามที่คุณพิมพ์ เพื่อให้แก้คำแปลด้วยมือได้ ตัวหนา ตัวเอียง ขีดฆ่า สปอยเลอร์ ลิงก์ การกล่าวถึง อีโมจิแบบกำหนดเอง คำพูดอ้างอิง โค้ด และบล็อกโค้ด จะอยู่ในที่ของมันในข้อความที่แปลแล้ว ขีดเส้นใต้เป็นสิ่งเดียวที่หายไป ถ้าแปลไม่สำเร็จ ข้อความจะถูกกักไว้ เหตุผลจะแสดงขึ้น และข้อความของคุณจะกลับไปที่ช่องพิมพ์ ในการตั้งค่าคุณเลือกให้ส่งไปโดยไม่แปลแทนได้

ทุกอย่างที่ได้รับแปลได้จากเมนูคลิกขวาบนข้อความ และคำตอบจะขึ้นในการ์ดข้าง ๆ และเมื่อแม้แต่คำแปลก็ยังไม่ช่วยให้เข้าใจ เพราะตัวย่อ คำที่ใช้กันแค่ในประเทศเดียว หรือมุกที่รู้กันแค่สองคน **อธิบาย** ในเมนูเดียวกันจะบอกว่าเป็นภาษาอะไร ขยายตัวย่อออกมา และอธิบายว่าเขาหมายถึงอะไร ตัวนี้ปิดอยู่จนกว่าคุณจะเปิดในการตั้งค่า

เปิด **ใช้ข้อความล่าสุดเป็นบริบท** แล้วข้อความล่าสุดไม่กี่ข้อความของบทสนทนาจะถูกส่งไปพร้อมกับทุกคำขอ คำว่า "ครับ" สั้น ๆ หรือ "วางไม่ได้" จึงไปถึงอย่างที่ตั้งใจ ตัวนี้ปิดอยู่จนกว่าคุณจะเปิดเอง เพราะมันส่งข้อความของคนอื่นไปให้ผู้ให้บริการของคุณ คุณยังปักหมุดคลังคำของตัวเองได้ด้วย ทั้งคำที่ห้ามแปล คำเฉพาะที่ผูกกับคำแปลตายตัว เพศทางไวยากรณ์ที่ใช้กับตัวคุณเอง และจะพูดกับอีกฝ่ายแบบสุภาพหรือไม่

ข้อความเดียวก็เก็บบางส่วนของตัวเองไว้ได้ ใส่คำหรือวลีไว้ระหว่างแบ็กสแลชสองตัว `\carpe diem\` แล้วมันจะออกไปตรงตามที่คุณพิมพ์ โดยไม่มีแบ็กสแลช ส่วนแบ็กสแลชที่ต้นบรรทัดจะเก็บทั้งบรรทัดนั้นไว้ โค้ดจะไม่ถูกแปลเลย ไม่ว่าจะเขียนไว้ในเครื่องหมายแบ็กทิกหรือจัดรูปแบบเป็นโค้ด

**AI Learn** มีไว้สำหรับภาษาที่คุณกำลังเรียน เปิดมันในการตั้งค่า แล้วในแชทที่คุณเปิดไว้ สิ่งที่คุณเขียนด้วยตัวอักษรของภาษาที่คุณแปลไปจะออกไปตรงตามที่พิมพ์ โดยมีประโยคที่เจ้าของภาษาจะเขียนอยู่ข้างใต้ และทำเครื่องหมายคำที่เปลี่ยนไว้ บรรทัดนั้นเห็นเฉพาะคุณ **สิ่งที่แก้ไป** ในการตั้งค่าเก็บห้าสิบรายการล่าสุด และ **แก้ให้** ในเมนูของข้อความของคุณเองจะถามใหม่อีกครั้ง

ใต้ข้อความที่คุณส่งไปแล้วสามารถเก็บต้นฉบับไว้ได้ โดยเห็นเฉพาะคุณคนเดียว เพื่อให้เห็นว่าคุณพิมพ์อะไรไปจริง ๆ ตัวนี้ปิดอยู่จนกว่าคุณจะเปิดเอง คำสั่งบอตอย่าง `/start` และสิ่งที่ปุ่มของบอตส่ง จะออกไปตามที่เป็นทุกประการ หน้าจอพูดได้ 16 ภาษา และจะตามภาษาของ Telegram จนกว่าคุณจะเลือกเป็นอย่างอื่น

## ผู้ให้บริการ

คีย์ API คุณนำมาเอง และมันยังเป็นของคุณ สคริปต์นี้ไม่มีเซิร์ฟเวอร์แปลภาษาของตัวเองและไม่เคยเห็นคีย์ของใคร

| ผู้ให้บริการ | โควตาฟรี |
|---|---|
| Groq | มี |
| Google Gemini | มี |
| Z.ai GLM | มี และเข้าถึงได้ในที่ที่อีกสองรายถูกปิดกั้น |
| Anthropic Claude | ไม่มี |
| อื่น ๆ (API ใดก็ได้ที่เข้ากันได้กับ OpenAI) | แล้วแต่ผู้ให้บริการ |

ตั้งผู้ให้บริการสำรองไว้ต่อท้ายรายแรกได้สูงสุดสี่ราย เมื่อรายแรกแน่น โควตาหมด หรือปฏิเสธคำขอ คำแปลจะไปทางรายถัดไปเอง และจะมีการแจ้งเตือนสั้น ๆ บอกว่าทำไมรายแรกถูกข้าม เพียงครั้งเดียว ไม่ใช่ทุกข้อความ

คีย์ของคุณอยู่ในที่เก็บของตัวจัดการ userscript และคำขอออกไปผ่านตัวจัดการ ไม่ใช่จากหน้าเว็บ ข้อความของคนอื่นจะไปถึงผู้ให้บริการของคุณก็ต่อเมื่อคุณสั่งให้แปลหรืออธิบายข้อความใดข้อความหนึ่ง หรือระหว่างที่ **ใช้ข้อความล่าสุดเป็นบริบท** เปิดอยู่เท่านั้น

## การติดตั้ง

AI Translate for Telegram ทำงานใน Telegram Web บนเบราว์เซอร์ และไม่ทำงานที่อื่น เพราะแอป Telegram ขยายความสามารถไม่ได้ ไคลเอนต์ทั้งสองของ Telegram Web ใช้ได้ทั้งคู่ คือ Web A และ Web K

ติดตั้ง [Tampermonkey](https://www.tampermonkey.net/) หรือตัวจัดการ userscript ตัวอื่น แล้วเปิด [ai-translate.user.js](https://github.com/mozumidesu/ai-translate-telegram/raw/main/dist/ai-translate.user.js) ตัวจัดการจะถามว่าจะติดตั้งไหม แล้วจากนั้นจะคอยอัปเดตให้จากที่นั่นเอง เปิด [web.telegram.org](https://web.telegram.org/) แล้วโหลดหน้าใหม่

จากนั้นคลิกปุ่มแปลในแถบพิมพ์แล้วกด **การตั้งค่าทั้งหมดของปลั๊กอิน** หรือหารายการเดียวกันในเมนูของตัวจัดการ userscript เลือกผู้ให้บริการ แล้ววางคีย์ของคุณ ครั้งแรกที่สคริปต์ติดต่อผู้ให้บริการของคุณ ตัวจัดการอาจถามว่าอนุญาตไหม ให้อนุญาตที่อยู่นั้น ใน Tampermonkey ใช้ **Always allow domain** จากนั้นเปิดแชทสักแชท ก็เป็นอันเสร็จ

## การอัปเดต

ตัวจัดการ userscript จะหาเวอร์ชันใหม่ตามรอบของมันเอง จากบรานช์ `main` ของรีโพซิทอรีนี้ ปุ่ม **ตรวจหาอัปเดต** ที่ด้านล่างของการตั้งค่าจะถามทันที และถ้ามีของใหม่ก็จะเปิดสคริปต์ใหม่ในตัวจัดการให้ ยืนยันที่นั่นแล้วโหลดหน้าใหม่

## การถอนการติดตั้ง

ลบสคริปต์ในตัวจัดการ userscript ไม่มีอะไรอื่นถูกติดตั้ง จึงไม่มีอะไรอื่นต้องเอาออก

## แจ้งอะไรสักอย่าง

ไอคอนซองจดหมายด้านบนของหน้าตั้งค่าจะเปิดหน้าต่างสำหรับรายงานข้อผิดพลาดและคำขอ แนบภาพหน้าจอได้ด้วย ลิงก์เซิร์ฟเวอร์สนับสนุนก็อยู่ในหน้าต่างเดียวกัน รายงานหนึ่งฉบับจะมีสิ่งที่คุณเขียน ภาพหน้าจอที่คุณแนบ ชื่อและ id ใน Telegram ของคุณเพื่อให้คำตอบไปถึงคุณได้ และบิลด์ที่คุณใช้อยู่ มันไม่เคยมีคีย์หรือการตั้งค่าใด ๆ คุณยัง[เปิด issue](https://github.com/mozumidesu/ai-translate-telegram/issues) บน GitHub ได้ด้วย
