# AI Translate for Telegram

好きな AI モデルでメッセージを翻訳する Telegram 用のユーザースクリプトです。書き方を整えてしまわずに翻訳します。

送るメッセージは、オンにしたチャットで、送信前に翻訳されます。受け取ったメッセージは、そのメッセージのメニューから頼んだときに翻訳されます。[Discord 用の AI Translate プラグイン](https://github.com/mozumidesu/ai-translate)の翻訳コアを、同じプロバイダーとともに使っています。

## なぜもう一つ翻訳機を

機械翻訳は文章のために作られています。チャットは文章ではありません。小文字で、言いかけのままで、顔文字で成り立っていて、句点がないこと自体が何かを伝えています。たいていの翻訳機はそれを黙って整えてしまい、相手側には誰か別の人が書いた定型文が届きます。

これはそこに手を入れないために作りました。書いていない句読点を足さず、小文字のままにしたところを大文字にせず、改行は置いた場所に残し、顔文字は訳す単語ではなく顔だと知っています。

## できること

自動翻訳はチャットごとに設定するので、本当に必要な会話にだけ働きます。入力欄の翻訳ボタンを左クリックするとパネルが開き、右クリックか Shift キーを押しながらのクリックで、今のチャットのオンとオフが切り替わります。チャットがオンのあいだ、ボタンはアクセントカラーになります。

入力したものは翻訳が届くまで待つので、相手には翻訳だけが見えます。編集は入力したとおりに送られるので、翻訳を手で直せます。太字、斜体、取り消し線、スポイラー、リンク、メンション、カスタム絵文字、引用、コード、コードブロックは、翻訳したメッセージでも元の場所に残ります。落ちるのは下線だけです。翻訳に失敗すると、メッセージは送られずに止まり、理由が表示され、文字は入力欄に戻ります。設定で、代わりに翻訳せずに送るよう選ぶこともできます。

受け取ったものは、どれでもメッセージの右クリックメニューから翻訳でき、答えはその横のカードに出ます。略語や、ある国でしか使わない言葉や、二人だけに通じる冗談のせいで、翻訳しても意味がわからないときは、同じメニューの **説明する** が言語を言い当て、略語をほどき、何が言いたかったのかを説明します。これは設定でオンにするまで切ってあります。

**直前のメッセージを文脈として使う** をオンにすると、会話の直近のメッセージがリクエストと一緒に送られるので、ひとことの「うん」や「貼れない」も意図どおりに届きます。ほかの人のメッセージをプロバイダーに送ることになるので、自分でオンにするまで切ってあります。自分の語彙を決めておくこともできます。絶対に訳さない語、訳し方を一つに固定する語、自分に使う文法上の性、相手に丁寧な言い方をするかどうか。

一つのメッセージが自分の一部をそのまま残すこともできます。語句をバックスラッシュ二つで囲むと、`\carpe diem\` のように、入力したとおりに、バックスラッシュだけ外れて送られます。行頭のバックスラッシュはその行全体を残します。コードは、バッククォートで囲んで書いたものも、コードとして書式設定したものも、決して訳されません。

**AI Learn** は学んでいる言語のための機能です。設定でオンにすると、オンにしたチャットで、翻訳先の言語の文字で書いたものは入力したとおりに送られ、その下にネイティブスピーカーなら書いたであろう文が、変えた語に印をつけて表示されます。その行は自分にしか見えません。設定の **添削の記録** には直近の五十件が残り、自分のメッセージのメニューにある **添削する** でもう一度尋ねられます。

送ったメッセージの下に原文を残すこともできます。自分にだけ見えるので、実際に何を入力したか確かめられます。これは自分でオンにするまで切ってあります。`/start` のようなボットコマンドや、ボットのボタンが送るものは、そのままの形で送られます。画面の言語は 16 言語で、指定しない限り Telegram の言語に合わせます。

## プロバイダー

API キーはご自身のものを使い、あなたのものであり続けます。このスクリプトに自前の翻訳サーバーはなく、誰かのキーを見ることもありません。

| プロバイダー | 無料枠 |
|---|---|
| Groq | あり |
| Google Gemini | あり |
| Z.ai GLM | あり。前の二つが使えない地域でも届きます |
| Anthropic Claude | なし |
| その他（OpenAI 互換の API ならどれでも） | プロバイダーによる |

予備のプロバイダーを四つまで、一つ目の後ろに置けます。一つ目が混んでいるとき、枠を使い切ったとき、リクエストを断られたときは、翻訳は自動で次のプロバイダーを通ります。一つ目が断った場合は、その理由を伝える短い通知が出ます。毎回ではなく、一度だけです。

キーはユーザースクリプトマネージャーの保存領域に残り、リクエストはページからではなくマネージャー経由で出ます。ほかの人のメッセージがプロバイダーに届くのは、そのどれかの翻訳や説明を頼んだときと、**直前のメッセージを文脈として使う** がオンのあいだだけです。

## 導入

AI Translate for Telegram はブラウザーの Telegram Web で動き、それ以外では動きません。Telegram のアプリは拡張できないからです。Telegram Web の二つのクライアント、Web A と Web K のどちらでも使えます。

[Tampermonkey](https://www.tampermonkey.net/) か、ほかのユーザースクリプトマネージャーを入れて、[ai-translate.user.js](https://github.com/mozumidesu/ai-translate-telegram/raw/main/dist/ai-translate.user.js) を開きます。マネージャーがインストールを尋ね、そのあとはそこから自動で更新します。[web.telegram.org](https://web.telegram.org/) を開いて、ページを再読み込みします。

それから入力欄の翻訳ボタンをクリックして **プラグインの全設定** を押すか、ユーザースクリプトマネージャーのメニューで同じ項目を探し、プロバイダーを選んでキーを貼り付けてください。スクリプトが初めてプロバイダーに接続するとき、マネージャーが許可を求めることがあります。そのアドレスを許可してください。Tampermonkey では **Always allow domain** です。あとはチャットを一つオンにすれば完了です。

## 更新

ユーザースクリプトマネージャーは、自分のタイミングで、このリポジトリの `main` ブランチから新しい版を探します。設定のいちばん下の **アップデートを確認** はそれをすぐに尋ね、新しい版があればマネージャーで新しいスクリプトを開きます。そこで確定してから、ページを再読み込みしてください。

## 削除

ユーザースクリプトマネージャーでスクリプトを削除します。ほかには何も入れていないので、ほかに消すものもありません。

## 報告する

設定ページの上部にある封筒から、不具合の報告や要望のための画面が開きます。スクリーンショットも添えられます。サポートサーバーへのリンクも同じ画面にあります。報告に含まれるのは、書いた内容、添えたスクリーンショット、返事が届くように Telegram の名前と ID、そして使っているビルドです。キーや設定が含まれることはありません。GitHub で [issue を開く](https://github.com/mozumidesu/ai-translate-telegram/issues)こともできます。
